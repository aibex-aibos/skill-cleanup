# skill-cleanup

Skill `cleanup` von AIbex AIOS, Version 0.1.0 (Gerüst, noch nicht spezifiziert): schließt eine Session ab, sodass sie archiviert werden kann und eine neue Session nahtlos weitermacht. Er räumt auf, stellt die Integrität her, pusht, schreibt die Übergabe und meldet zum Schluss mit einer abgehakten Liste.

## Holen

```bash
aios --fetch skill-cleanup
```

Aufruf ab dem nächsten Chat mit `/cleanup` oder einem Satz wie „Räum auf und schließ die Session ab".
